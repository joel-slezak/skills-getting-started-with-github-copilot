# Math Game

## Features

- Practice addition problems
- Practice subtraction problems
- Keep track of score and questions answered

## Getting Started

1. Install the dependencies:

   ```
   pip install -r ../requirements.txt
   ```

2. Run the application from the repository root:

   ```
   uvicorn src.app:app --reload
   ```

3. Open your browser and go to:
   - Math game: http://localhost:8000/static/index.html
